Connect Google Sheets

One-time setup — takes about 10 minutes.

Step 1 — Create the SheetGo to sheets.google.com, create a new spreadsheet, and name it Budget History.
Step 2 — Open Apps ScriptIn the Sheet, click Extensions → Apps Script. Delete any existing code.
Step 3 — Paste the scriptCopy the budget-script.gs file and paste it into the editor. Click Save.
Step 4 — DeployClick Deploy → New deployment. Set type to Web app, execute as Me, access Anyone. Authorize.
Step 5 — Copy the URLPaste the Web app URL below.
